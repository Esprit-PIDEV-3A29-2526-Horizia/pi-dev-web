# 🚀 Horizia - Plateforme de gestion de voyages et événements

## 📋 Description
Horizia est une plateforme web développée avec **Symfony 5.13** permettant la gestion et la réservation de voyages, événements, logements et locations de véhicules.

## 🛠️ Technologies utilisées
- **Backend**: Symfony 5.13, PHP 8.2, Doctrine ORM
- **Frontend**: Twig, Bootstrap 5, jQuery
- **Base de données**: MySQL/MariaDB
- **Services externes**: Stripe, Brevo, OpenWeatherMap, Gemini AI

## 📦 Installation

### Prérequis
- PHP 8.2+
- Composer
- MySQL/MariaDB
- Symfony CLI
